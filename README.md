# 你的下一分在哪里

AI 时代的公考备考方法 · V1.1 · 卷蜂啦·林照 著

<img src="assets/cover.jpg" alt="《你的下一分在哪里》封面" width="320">

> 明晚只有两个小时，你究竟该押在哪里？

**下一分方法论：** 用自己的真实记录，判断下一小时押在哪个具体问题上；练完复测，一直验到考场拿得到分。

这是一本写给公务员考试考生的备考方法书，全书免费开放，欢迎非商业转发和转载。

这本书不能保证你考上，任何负责任的方法都不该做这样的保证。书里不给全国统一的分数线、秒数和天数，门槛都从你的记录里来。
